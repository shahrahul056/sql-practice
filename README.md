# SQL Practice Project

Practice queries I wrote while learning SQL, using PostgreSQL.

## Tables used
- employees (8 rows)
- departments (4 rows)
- staff (7 rows)

## Topics covered
- SELECT, WHERE, ORDER BY, LIMIT, LIKE, IN, BETWEEN
- COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN, finding unmatched rows with IS NULL
- INSERT, UPDATE, DELETE

## How to use
1. Open sql_practice.sql in pgAdmin.
2. Run the setup section first to create the tables.
3. Run the queries one by one.
